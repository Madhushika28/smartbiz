# SmartBiz

## Business Intelligence & Sales Forecasting Platform

SmartBiz is a full-stack web application designed to help businesses analyze sales performance, monitor revenue and profit, evaluate product performance, and forecast future sales using machine learning.

## Planned Features

- Sales Analytics Dashboard
- CSV Sales Data Import
- Revenue and Profit Analysis
- Product Performance Analysis
- Machine Learning-Based Sales Forecasting
- Automated Business Reports
- Authentication and Role-Based Access Control

## Technology Stack

| Layer | Technology |
|---|---|
| Frontend | React, Vite, Tailwind CSS |
| Backend | Python, FastAPI |
| Database | PostgreSQL |
| Data Analytics | Pandas |
| Machine Learning | scikit-learn |
| Version Control | Git, GitHub |

## Project Structure

- `frontend/` - React application
- `backend/` - FastAPI application
- `docs/` - Project documentation
- `sample-data/` - Sample datasets

## Currency

The platform will use Sri Lankan Rupees (LKR) as its default currency.
